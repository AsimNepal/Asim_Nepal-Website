# Asim Nepal — Personal Website

A responsive academic portfolio built with HTML, CSS, and JavaScript. No build tools or paid hosting required.

## Deploy with GitHub and Netlify

1. Create a GitHub repository named `asimnepal-website`.
2. Upload `index.html`, `styles.css`, `script.js`, and the entire `assets` folder to the repository root.
3. In Netlify, select **Add new project → Import an existing project → GitHub** and select the repository.
4. For this static site, leave the build command empty and use `.` as the publish directory.
5. Click **Deploy**. Netlify will give you a `netlify.app` address.
6. To use `asimnepal.com`, go to Netlify **Domain management → Add a domain you already own**, then follow its DNS instructions in Porkbun.

## Edit the site

- `index.html`: text, sections, and links.
- `styles.css`: design and animations.
- `script.js`: scroll animations, progress bar, and mobile menu.
- `assets/asim-nepal.webp`: homepage photo.
- `assets/favicon.svg`: browser tab icon.

The site deliberately does not include conference presentations, a CV download, or future career plans, since those were not requested for publication.
